# Anjaneya Gym - Digital Gym Membership and Payment Management System

## 📌 Project Overview

Anjaneya Gym is a web-based Gym Management System developed to simplify gym membership registration, login, member management, and online payment processing.

The application provides a user-friendly interface for gym members and an administration system for managing member information and payments.

## 🚀 Features

- User Registration
- User Login
- OTP-based Email Verification
- Gym Membership Management
- Member Dashboard
- Admin Dashboard
- Membership Plan Management
- Online Payment using Razorpay
- Payment Order Creation
- Payment Verification
- Payment History
- Member CRUD Operations
- Secure handling of API credentials
